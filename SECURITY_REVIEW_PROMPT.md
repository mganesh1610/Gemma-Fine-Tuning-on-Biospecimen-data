# Pre-ship security review prompt

Review this repository and its reachable Git history for security vulnerabilities before merging a pull request. Inspect notebook source, metadata, and saved outputs for credentials, private data, session URLs, and internal hostnames. Follow any data or authorization path to a concrete affected resource. Check that upstream code fetched into Colab is pinned to an approved revision before using sensitive data. Assess GitHub Actions permissions and untrusted pull-request execution. Separate confirmed vulnerabilities from leads that need owner or deployment validation, with repository-relative source evidence and the smallest effective fix. Do not run notebook cells, request a published Colab URL, or use real data or credentials during review.
